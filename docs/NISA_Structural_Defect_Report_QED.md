$$AD(t) = GDP(t) + \frac{dD(t)}{dt}$$

$$AD_{Market}(t) = Real\_Demand(t) + \frac{d(NISA\_Inflow)}{dt}$$

## 【補足解説】この数式が意味する「NISAの正体」

$$AD_{Market}(t) = Real\_Demand(t) + \frac{d(NISA\_Inflow)}{dt}$$

この式は、一見難しそうに見えますが、実は **「今の株価がなぜ上がっているのか？」** という種明かしを、たった一行で表現したものです。

### 1. $Real\_Demand(t)$（実体としての需要）
これは、 **「その企業がどれだけ世の中の役に立ち、実際に稼いでいるか」** という、いわば「実力」の部分です。
美味しいパンを作ったり、便利な道具を開発したりして得た、地に足のついた価値です。

### 2. $\frac{d(NISA\_Inflow)}{dt}$（NISAという名の「注ぎ込みの勢い」）
ここが最も重要なポイントです。$\frac{d}{dt}$ という記号は、数学で「勢い（変化のスピード）」を表します。

今の株価を押し上げているのは、企業の実力（左側の項）だけではありません。新NISAによって、毎月決まった日に、数千万人の日本人が機械的に「買い」を入れる。この **「お金を市場に注ぎ込む勢い」** が、無理やり数字を吊り上げているのです。

イメージするなら、 **「バスタブの水の量（株価）」** です。
* 本来は、お風呂を使う人のニーズに合わせて水を増やすべきですが（実体需要）、
* 今は、ただ **「蛇口を全開にしているから、水位が上がっているだけ」** （NISAの勢い）なのです。

この数式が教えてくれる最大の警告は、 **「勢いが止まれば、数字は落ちる」** ということです。

バブルが崩壊する時、企業の実力が急にゼロになるわけではありません。ただ、 **「新しくお金を注ぎ込む勢い」が衰えた瞬間に、魔法が解ける** のです。
